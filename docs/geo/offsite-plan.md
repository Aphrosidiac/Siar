# Off-site plan: Siar

Answer engines recommend what third parties say about a product, and Siar is a day old with zero mentions. In order of
expected effect for a developer API (sourced: offsite-authority.md). Every item is real activity under the real name.
No astroturfing, no self-ranked lists, no review gating.

1. **The public repo is the strongest asset.** github.com/Aphrosidiac/Siar: make sure its README opens with one plain
   sentence (what Siar is + siaran.my), add topics (`social-media-api`, `mcp-server`, `instagram-api`, `tiktok-api`…)
   and link the site. GitHub pages are heavily cited for developer queries.
2. **MCP directories**: list the Siar MCP server where agent builders look (the official MCP registry, Smithery, Glama,
   mcp.so, awesome-mcp-servers via PR). This matches prompt strata p008/p009/p037.
3. **npm**: when the SDK, CLI and MCP packages are published (Fakhrul's yes needed), each package page links siaran.my.
4. **API directories and comparisons the engines already cite**: fill this in from the wave-0 cited-domain list
   (`ai_visibility.py` prints it). Likely: Postman API Network, RapidAPI Hub, G2 (category "Social Media APIs"),
   Product Hunt launch, "best social media API" roundups on dev.to / Medium. Pitch the roundup authors with a factual
   one-paragraph summary + the pricing difference (per organization, not per account).
5. **Answer real questions where developers ask them**: Stack Overflow and Reddit (r/webdev, r/SaaS, r/socialmedia)
   threads about posting to Instagram/TikTok/LinkedIn via API. Answer the question first, disclose the affiliation,
   link the network's error page on siaran.my only when it is the answer. A few genuine answers a week, no more.
6. **YouTube**: the walkthrough clips already exist (`apps/site/public/clips`). One 2–3 minute "post to 15 networks with
   one request" video on the FF Dev Studio channel, with siaran.my in the description.
7. **LinkedIn**: the FF Dev Studio page posts the launch and the changelog; Fakhrul's own profile lists Siar.
8. **Original data, later**: once there is traffic, an anonymised "what the networks reject most" report built from the
   error relay (a codes × networks table) is the kind of statistic engines cite. Needs real volume first.

Not doing: Wikipedia/Wikidata (not notable yet), paid "listicle" placements, review swaps.
