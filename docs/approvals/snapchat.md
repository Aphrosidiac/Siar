# Snapchat — Public Profile API

Access is partner-gated. Siar's adapter is built against the published docs and mock-tested.

## [F]
1. Create a Snapchat **Public Profile** for FF and a Snap business account (business.snapchat.com).
2. Snap Kit / developer portal → create an app **Siar**, OAuth redirect
   https://api.siaran.my/api/v1/social-account/callback/SNAPCHAT, privacy policy URL.
3. Apply for Public Profile API access (Stories, Saved Stories, Spotlight posting). Paste:
   *"Siar is a publishing tool. Creators and brands connect their own Public Profile to post
   Stories, Saved Stories and Spotlight videos they created, scheduled from one dashboard and
   API. We only act on the connected profile and only post content the profile owner uploaded."*
