# @siar/cli

JSON-first command line for the [Siar](https://siaran.my) unified social media API.

```bash
npm i -g @siar/cli
export SIAR_API_KEY=sk_live_…
siar teams:list
siar posts:create --team team_123 --networks BLUESKY,MASTODON --text "Shipped" --now
siar help
```

Run `siar help` for every command. `SKILL.md` documents the CLI for agent runtimes.
