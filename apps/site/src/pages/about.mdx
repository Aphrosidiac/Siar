Siar is one REST API for publishing, scheduling, commenting on and measuring social media across {NETWORKS.length} networks. It is built and operated by [FF Dev Studio]({COMPANY_URL}), a software studio in Malaysia.

## Why it exists

Every team that posts to social media ends up building the same thing: OAuth for a dozen networks, token refresh, media conversion, each network's quirks and limits, retries that must not double-post, and a way for customers to connect their own accounts. It is slow to build, easy to get subtly wrong, and has nothing to do with the product it supports. Siar is that layer, built once and run as a service.

## How we build it

- **One contract.** The OpenAPI document is the source of truth. The server mounts its routes from it, validates requests against it, and the SDK, CLI, MCP server and this documentation are generated from it.
- **Real network behaviour.** Adapters are tested against mock servers written from each network's own documentation, and the limits and error references on this site are generated from the same code that enforces them.
- **Plain pricing.** Plans are per organization, not per connected account.
