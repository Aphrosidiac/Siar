## Conventions

- **JSON in, JSON out.** Send `content-type: application/json`. File uploads use `multipart/form-data`.
- **Timestamps** are ISO 8601 in UTC.
- **Ids** are opaque strings. Do not parse them.
- **Errors** share one envelope; see [errors](/docs/errors).
- **Machine-readable contract:** [/openapi.json](/openapi.json). The [SDK, CLI and MCP server](/docs/sdk-cli-mcp) are generated from it.
- **For LLMs:** [/llms.txt](/llms.txt) summarises the product and links the key pages.
