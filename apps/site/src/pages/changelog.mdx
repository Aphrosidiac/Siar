## v1.0 · October 2026

The first release of the Siar API.

- **{NETWORKS.length} networks:** {NETWORKS.map((n) => n.name).join(', ')}.
- **Publishing and scheduling** with per-network payloads validated against each network's limits, atomic claiming so a post is never sent twice, retries and first comments.
- **Media:** simple, from-URL, large and multipart uploads, with conversion and per-network checks.
- **Accounts and teams:** OAuth for every network behind one endpoint, hosted connect links, channel selection and reconnect detection.
- **Comments, analytics and imports:** comment publishing and import, normalised post and account analytics with raw payloads, post history import and CSV import.
- **Webhooks:** {WEBHOOK_EVENTS.length} signed event types with retries, a delivery log and resend.
- **X credit:** prepaid balance with a hold, capture and release ledger, and a quote endpoint.
- **{operations().length} operations** in one OpenAPI document, served at [/openapi.json](/openapi.json).
- **Tooling:** TypeScript SDK, JSON-first CLI and MCP server (all version 0.1.0).
- **Pricing:** Free, Pro, Business and Enterprise plans per organization; see [pricing](/pricing).
